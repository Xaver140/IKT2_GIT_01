# IKT2_GIT_01

Ez a repository az IKT2 tantárgy Git és GitHub alapjainak gyakorlására készült.
A feladat célja verziókezelés, branchek, pull requestek és egy statikus weboldal elkészítése.

# Felhasznált technológiák

- Git
- HTML
- CSS
- JavaScript

- **HTML5:** A weboldalak szerkezetének leírására szolgáló nyelv, amely lehetővé teszi címek, bekezdések, listák, táblázatok és egyéb elemek létrehozását.
```html
<!DOCTYPE html>
<html lang="hu">
<head>
    <meta charset="UTF-8">
    <title>Példa HTML oldal</title>
</head>
<body>
    <h1>Üdv az IKT2 feladatban!</h1>
    <p>Ez egy rövid HTML5 példa.</p>
    <ul>
        <li>Listaelem 1</li>
        <li>Listaelem 2</li>
    </ul>
</body>
</html>
```


**Git:** Verziókezelő rendszer, amely lehetővé teszi a kódváltoztatások követését, a különböző ágak létrehozását és a kollaborációt több fejlesztő között.
```bash

git init
git add README.md
git commit -m "Első commit"
```

**CSS3:** Stíluslap nyelv, amely a weboldalak kinézetének megtervezésére szolgál. Lehetővé teszi színek, betűtípusok, elrendezések, animációk és reszponzív dizájnok alkalmazását.
```css
body {
    background-color: #f0f0f0;
    font-family: Arial, sans-serif;
}

h1 {
    color: #007ACC;
    text-align: center;
}
```

**JavaScript:** Programozási nyelv, amely a weboldal interaktivitását biztosítja. Segítségével dinamikus tartalmak, űrlapok, eseménykezelés és animációk hozhatók létre.

```javascript
const year = new Date().getFullYear();
console.log(year);
```
