GIT alapvető parancsai

Alap parancsok

git init – Új helyi Git-repozitórium létrehozása az aktuális mappában.

git status – Megmutatja az aktuális állapotot: módosított, staged és nem követett fájlokat.

git add . – Az összes módosított fájlt hozzáadja a staging area-hoz.

git commit -m "üzenet" – Elmenti a staging area-ban lévő változtatásokat egy commitba.

git log – Kilistázza az eddigi commitokat a történetben.
